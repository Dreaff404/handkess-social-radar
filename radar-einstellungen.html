YouTube-API-Schlüssel

HandKess Social Radar holt Views, Likes, Kommentare und Abonnenten über die offizielle YouTube Data API v3 – mit deinem eigenen, kostenlosen Schlüssel. Er wird nur an googleapis.com geschickt.
  1. console.cloud.google.com öffnen und ein Projekt anlegen (z. B. „HandKess Social Radar“).
  2. „APIs & Dienste“ → „Bibliothek“ → „YouTube Data API v3“ → aktivieren.
  3. „Anmeldedaten“ → „Anmeldedaten erstellen“ → „API-Schlüssel“.
  4. Schlüssel bearbeiten → „API-Einschränkungen“ → nur „YouTube Data API v3“ erlauben.
  5. Schlüssel hier einfügen, speichern, testen.

Auswertung

Pro 50 Videos kostet ein Abruf etwa 2 von 10.000 Einheiten des täglichen Gratis-Kontingents.

Automatisch nachladen in Entwicklung

Ausgewählte gespeicherte YouTube-Kanäle werden einmal täglich sparsam aktualisiert – Kanal-Kennzahlen und die neuesten Videos und Shorts. Daraus entstehen der Verlauf der Kanal-Views („Views in 7 / 30 Tagen“) und Messpunkte für neue Videos. Höchstens 10 Kanäle.
Einzelne Videos trackst du direkt auf der Videoseite („◎ Video tracken“): gemessen wird nach 1, 4, 8, 12, 24 Stunden, 2 und 7 Tagen.
Wichtig: Das läuft nur, solange Chrome geöffnet ist; verpasste Messungen holt Chrome beim nächsten Start nach (mit der tatsächlichen Uhrzeit). Für eine lückenlose Messung braucht es später einen eigenen Server.
