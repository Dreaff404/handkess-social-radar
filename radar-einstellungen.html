YouTube-API-Schlüssel

HandKess Social Radar holt Views, Likes, Kommentare und Abonnenten über die offizielle YouTube Data API v3 – mit deinem eigenen, kostenlosen Schlüssel. Er wird nur an googleapis.com geschickt.
  1. console.cloud.google.com öffnen und ein Projekt anlegen (z. B. „HandKess Social Radar“).
  2. „APIs & Dienste“ → „Bibliothek“ → „YouTube Data API v3“ → aktivieren.
  3. „Anmeldedaten“ → „Anmeldedaten erstellen“ → „API-Schlüssel“.
  4. Schlüssel bearbeiten → „API-Einschränkungen“ → nur „YouTube Data API v3“ erlauben.
  5. Schlüssel hier einfügen, speichern, testen.

Auswertung

Pro 50 Videos kostet ein Abruf etwa 2 von 10.000 Einheiten des täglichen Gratis-Kontingents.
